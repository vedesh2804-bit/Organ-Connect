# OrganConnect — Front-end academic prototype

A modern responsive website concept for an Organ Donator and Finder awareness project.

## Pages
- `index.html` — home / project overview
- `register.html` — sample donor-interest form
- `find.html` — searchable fictional profile directory
- `request.html` — demo request-flow page
- `contact.html` — about and project information

## Technologies
- HTML5
- CSS3 (responsive layout)
- Vanilla JavaScript
- Browser `localStorage` for demo-only form entries

## Run the project
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the navigation links to test each page.

No build tools or package installation are required.

## Important safety and scope note
This is an academic UI prototype. All built-in directory profiles are fictional. Form submissions are stored only in the current browser's localStorage. The website is not a donor registry, medical service, compatibility checker, or emergency service. Do not enter real personal, patient, or medical information. Real organ donation and transplantation must be handled through authorized healthcare professionals and official systems.

## Suggested next development phase
For a real production system, the team would need a secure backend, authentication, privacy and security review, legal/regulatory review, and integration with authorized medical institutions. Do not connect this student demo to real patient or donor records.
