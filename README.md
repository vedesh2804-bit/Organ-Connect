# ❤️ OrganConnect – Give Hope, Share Life

**OrganConnect** is a modern web-based Organ Donator and Finder platform designed to promote organ donation awareness and demonstrate donor profile discovery through a simple, user-friendly interface.

Our goal is to use technology to spread awareness, encourage informed decisions, and demonstrate how a digital platform can support organ donation initiatives.

## 🌟 Features

- 🏠 **Home Page** – Attractive and modern landing page.
- ❤️ **Donor Registration** – Interactive donor interest registration form.
- 🔍 **Find Donors** – Search and filter fictional donor profiles.
- 📝 **Request Page** – Demonstration of the request submission process.
- 📞 **Contact Page** – Project information and details.
- 📱 **Responsive Design** – Supports desktop, tablet, and mobile screens.
- 💾 **Local Storage** – Stores demo form submissions in the browser.

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension.

4. Open `index.html`.

5. Right-click and select **Open with Live Server**.

6. Explore the OrganConnect website.

## ⚠️ Disclaimer

OrganConnect is an academic demonstration project. All donor profiles and submissions are fictional sample data. This website is not an official donor registry, medical service, donor-matching system, or substitute for professional medical advice. Real organ donation and transplantation must be handled through authorized healthcare professionals and official systems.
